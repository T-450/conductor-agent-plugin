# HTML & CSS Style Guide Summary

## Conventions
- Use semantic HTML5 elements (`<header>`, `<main>`, `<nav>`, `<article>`, `<section>`, `<footer>`).
- Maintain accessibility: always provide `alt` text for images and proper `aria-*` attributes where necessary.
- CSS: Prefer modern layout tools (Flexbox, CSS Grid) and CSS custom properties (variables).
- Class Naming: Use kebab-case (`user-profile-card`) or utility-first classes.
- Responsive Design: Mobile-first media queries with relative units (`rem`, `em`, `%`).
