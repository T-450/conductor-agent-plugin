# Dart & Flutter Style Guide Summary

## Conventions
- Follow official `dart format` and Effective Dart rules.
- `UpperCamelCase`: Classes, enums, typedefs, extension types.
- `lowerCamelCase`: Variables, parameters, functions, getters/setters.
- `lowercase_with_underscores`: File names, package names, import prefixes.
- Use `final` and `const` as much as possible for widget definitions and immutability.
- Prefer sound null-safety idioms (`?.`, `??`, `??=`).
