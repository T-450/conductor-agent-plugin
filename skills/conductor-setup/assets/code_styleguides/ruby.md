# Ruby Style Guide Summary

## Conventions
- Follow the community Ruby Style Guide and RuboCop standards.
- 2 spaces per indentation level.
- `snake_case`: Methods, variables, file names.
- `PascalCase`: Classes, modules.
- `SCREAMING_SNAKE_CASE`: Constants.
- Use `?` suffixes for predicate methods returning boolean (`active?`, `valid?`).
- Prefer string interpolation `#{var}` over string concatenation.
