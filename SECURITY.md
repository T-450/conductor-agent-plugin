# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Conductor, please do not open a public issue.
Report it responsibly via GitHub Private Vulnerability Reporting or contact the maintainers directly.
All vulnerability reports will be acknowledged within 48 hours.
